{% comment %} El instalador de Windows sale de cada versión, así que su enlace va a «latest». Mac y Linux se empaquetan cada varias versiones: los suyos van a version_otros, la última release que los lleva, que el flujo de publicación calcula y escribe en _config.yml. Sin ese dato se cae a «latest». La versión solo se dice debajo del botón cuando no es la misma que la de Windows. {% endcomment %}
